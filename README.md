## What I Do

I build across three disciplines that most people keep separate:

- **Cloud & DevOps** — Security-gated CI/CD pipelines, Kubernetes on AWS EKS, zero-trust infrastructure with Terraform and OIDC
- **Full-Stack Engineering** — React, TypeScript, Vue, Node.js — from fintech dashboards to geospatial data platforms
- **Geospatial & Groundwater Research** — NASA GRACE/GRACE-FO satellite data, terrestrial water storage anomalies, remote sensing + Python pipelines for hydrological analysis across Nigeria

> *I build systems that run, analyse systems that move water underground, and ship both with engineering rigour.*
